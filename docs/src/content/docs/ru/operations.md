# Справочник операций

Каждый транспорт принимает **один и тот же набор операций** — все они проходят через
`applyOperations` в `@sharptown/core`. Эта страница — единый источник истины о том, что
делает каждый параметр.

## Параметры

| Параметр | Тип | Диапазон / значения | Действие |
| -------- | --- | ------------------- | -------- |
| `width` | число | ≥ 0 | Ширина изменения размера, в пикселях. |
| `height` | число | ≥ 0 | Высота изменения размера, в пикселях. |
| `rotate` | число | градусы | Поворот на N градусов. |
| `flip` | булево | — | Отражение по горизонтали. |
| `blur` | число | ≥ 0 (сигма) | Размытие по Гауссу. |
| `r` | число | 0–255 | Тонирование красного канала. |
| `g` | число | 0–255 | Тонирование зелёного канала. |
| `b` | число | 0–255 | Тонирование синего канала. |
| `grayscale` | булево | — | Обесцветить изображение. |
| `greyscale` | булево | — | Британский синоним `grayscale`. |
| `removeAlpha` | булево | — | Убрать альфа-канал. |
| `ensureAlpha` | булево | — | Гарантировать наличие альфа-канала. |
| `convertTo` | строка | см. ниже | Формат вывода. |

> Через транспорт REST каждое значение приходит как строка запроса, поэтому булевы — это
> буквальные строки `"true"` / `"false"`. Клиент и ядро нормализуют это за вас.

## Поддерживаемые форматы вывода

`convertTo` должен быть одним из:

```
webp · png · jpg · jpeg · avif · gif · heif
```

Что-либо иное порождает `InvalidOperationError` → HTTP `400` (`"Invalid convert format
target"`). Если опустить `convertTo`, изображение сохраняет исходный формат, а заголовок
`Content-Type` в ответе всё равно отражает то, что фактически произвёл Sharp.

## Порядок операций

`applyOperations` применяет шаги в фиксированном, разумном порядке независимо от того, как
вы их перечислили:

1. `removeAlpha`
2. `ensureAlpha`
3. тонирование (`r` / `g` / `b`)
4. `grayscale`
5. `blur`
6. `flip`
7. `rotate`
8. `resize` (`width` / `height`)
9. `convertTo`

## Правила валидации

- `width`, `height`, `blur` должны быть **неотрицательными целыми**.
- `r`, `g`, `b` должны быть целыми в диапазоне **`[0, 255]`**.
- `rotate` — любое целое (градусы).
- Значения вне диапазона или нечисловые порождают `InvalidOperationError`. Клиент проверяет
  их **до** отправки запроса, мгновенно падая с `SharptownError`.

## Лимиты для больших файлов (стриминг / gRPC)

При обработке очень больших изображений помните о пиксельных лимитах форматов вывода:

- **WebP** — до `16383 × 16383` px.
- **JPEG** — до `65535 × 65535` px.

Если карта превышает лимит WebP, конвертируйте в JPEG или примените `resize` в том же
запросе. Для гигабайтных входов предпочитайте `resize` / `convert` / `flip`; произвольный
`rotate` может потребовать больше памяти.
